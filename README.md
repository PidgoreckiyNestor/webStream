# petal (study clone)

Local Next.js replica of [petal.tech](https://petal.tech/) for visual/layout study.

**Not affiliated with Petal Technology LLC.** Do not deploy, index, or use as a product site.

## Run

```bash
cd app/petal
npm install
npm run dev
```

Open http://localhost:3000

## Captured

- Homepage sections: nav, hero + demo video, features, use cases, pricing, integrations, CTA, footer
- Tokens: `design-system/tokens.json` and `DESIGN.md`
- Screenshot: `.firecrawl/petal-screenshot.png`

`/contact`, `/login`, `/signup`, and `/legal/*` are stubs. `/pricing` jumps to `#pricing`.
